# 🚀 NetShip - Soluções Digitais Inovadoras em Angola

![NetShip Logo](./images/logo.png)

## 📋 Sobre o Projeto

**NetShip** é uma startup angolana focada na criação de soluções digitais inovadoras para impulsionar o crescimento de Angola. Desenvolvida por jovens programadores angolanos, a plataforma oferece serviços de desenvolvimento web, marketing digital, edição de vídeos e muito mais.

### ✨ Funcionalidades

- ✅ **Website Responsivo** - Design adaptável para todos os dispositivos
- ✅ **Chatbot Integrado** - Assistente virtual para atendimento ao cliente
- ✅ **SEO Otimizado** - Estrutura completa para melhor rankeamento
- ✅ **Design Moderno** - Interface com Tailwind CSS e animações suaves
- ✅ **Formulário de Contato** - Canal direto para clientes
- ✅ **Links para Redes Sociais** - Integração com Facebook, Instagram, LinkedIn e WhatsApp
